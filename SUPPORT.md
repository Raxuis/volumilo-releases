Issues are public. Never attach personal files, catalogues, transfer journals, credentials or real private paths. Use fictitious names and redact screenshots. / Les retours sont publics : aucun fichier personnel, catalogue, journal, identifiant ou chemin privé. Utilisez des noms fictifs et masquez les captures.

Please give the app version, macOS version, storage type, reproduction steps and exact message. / Indiquez les versions, le type de stockage, les étapes et le message exact.

The app is in development, locally signed and not notarized by Apple. Read the installation guide before trying it. Support and fixes have no guaranteed response time. / L’app est en développement, signée localement et non notariée par Apple. Consultez le guide. Aucun délai de réponse ou de correctif n’est garanti.
